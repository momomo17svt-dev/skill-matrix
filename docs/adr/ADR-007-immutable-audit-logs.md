# ADR-007: 不変監査ログと対象者スナップショットの保持

## ステータス
承認済み (Accepted)

## コンテキスト
内部統制・コンプライアンス要件として、社員が物理削除された後も過去の監査ログが欠落せず追跡可能である必要があります。

## 意思決定
1. 監査ログテーブル（`audit_logs`）は外部キー制約（Foreign Key）によるCASCADE DELETEを行わず、対象社員番号・氏名等のスナップショットを直接保存。
2. UPDATE / DELETE を一切行わない不変テーブル（Append-only）として運用。
3. すべての変更操作（登録、更新、削除、ログイン、パスワード変更等）で、変更前後のJSONスナップショットを記録。

## 結果と影響
- 社員退職や削除後も、誰がいつどのような変更を行ったかの証跡が完全維持。
