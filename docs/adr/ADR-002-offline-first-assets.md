# ADR-002: 完全オフライン運用とアセットローカル同梱

## ステータス
承認済み (Accepted)

## コンテキスト
本番運用環境は物理的または論理的にインターネットから切断された閉域環境です。

## 意思決定
1. 外部CDN（unpkg, cdnjs等）およびGoogle Fontsへのアクセスを全廃。
2. Webフォントはシステムフォントスタックを基本とし、アイコンは `lucide-react` をビルド時に完全ローカルバンドル。
3. ビルド成果物に外部通信URLが含まれていないかを自動検査するスクリプトを整備。

## 結果と影響
- ネットワーク切断環境下でもレンダリングブロックやリソース取得失敗が一切発生せず、高速に動作。
