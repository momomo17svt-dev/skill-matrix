# ADR-010: Cookie + Bearer トークンのハイブリッド認証および包括的多言語化 (i18n) の導入

## ステータス
承認済 (Accepted)

## コンテキスト
オープンソース版 SkillMatrix において、以下の要件・課題に対応する必要があった。
1. **多様な実行環境（HTTP / LAN / VPN / 各種ポート）における認証の安定性**:
   - HTTP 接続や IP アドレス直接アクセス環境において、ブラウザのセキュリティポリシー（Secure Cookie 破棄）により画面が空白になる事象を根本防止する。
2. **グローバル組織・OSS 利用者に向けた包括的な多言語対応（i18n）**:
   - 全画面（社員一覧、検索、ダッシュボード、設定、マスタ管理、監査ログ、各モーダル）を日本語・英語で完全に切り替え可能にする。
3. **UI / ナビゲーションの不具合解消**:
   - `NavLink` の前方一致によるサイドバーの重複選択バグの解消、および部署ツリーのフラット化による子部署選択機能の提供。

## 決定事項
1. **ハイブリッド認証（Cookie + Bearer Token）の採用**:
   - ログイン時に Cookie（`skillmatrix_session`）と同時にセッショントークン文字列（`token`）を返却。
   - フロントエンド（`api.ts` / `AuthContext`）はリクエストヘッダーに `Authorization: Bearer <token>` を自動付与。
   - バックエンドの `authMiddleware` は Cookie と Bearer ヘッダーの双方を透過的に検証・受理する。
2. **包括的多言語（i18n）キーの拡充**:
   - `packages/shared/src/i18n/ja.ts` および `en.ts` を同期管理し、全コンポーネントのハードコード文言を `t.xxx` に置換。
3. **ダッシュボードの資格保有ドーナツ円グラフ可視化**:
   - Recharts の PieChart を用いて、資格保有割合のグラフィカルな表示を追加。

## 影響・効果
- どのようなネットワーク構成やブラウザ環境でも認証エラーが発生しない堅牢な基盤を実現。
- 海外ユーザーを含むグローバルな開発組織でそのまま利用可能な OSS アプリケーションへと品質が向上。
