# ADR-008: 将来の外部社員マスタ連携を見据えたリポジトリ境界設計

## ステータス
承認済み (Accepted)

## コンテキスト
将来的に社員基本情報（氏名、社員番号、メール、部署、役職等）は全社の人事基盤マスタへ移行・外部連携される可能性があります。

## 意思決定
1. 社員基本情報操作を `IEmployeeRepository` インターフェース経由に抽象化。
2. スキル評価、資格、実務経歴等のSkillMatrix固有ドメインは、`employeeId`（または社員番号）を外部キー/論理キーとして疎結合に参照。
3. 将来外部REST/SCIM APIやSSOに移行する際も、SkillMatrix固有のコアロジックに影響を与えずにアダプタ差し替えを可能にする。

## 結果と影響
- 社員マスタ変更に伴う改修コストを局所化し、将来のエンタープライズ統合への柔軟性を確保。
