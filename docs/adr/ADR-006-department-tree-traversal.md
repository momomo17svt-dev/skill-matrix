# ADR-006: 階層ツリー組織のMaterialized Pathと認可解決

## ステータス
承認済み (Accepted)

## コンテキスト
組織は任意階層ツリーであり、部署長は「自部署＋配下の全子孫部署」を管理可能とする必要があります。

## 意思決定
1. 部署テーブルに `path` カラム（実体化パス: `/root/dept1/dept2`）を保持。
2. 部署長の管理対象スコープ判定を、`path LIKE '/.../dept%'` の単一インデックスクエリで高速解決。
3. 部署移動時はトランザクション内で配下パスを再帰更新。

## 結果と影響
- 複雑な再帰CTEクエリを不要にし、認可判定と集計のパフォーマンスを大幅に向上。
