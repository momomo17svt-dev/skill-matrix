# ADR-005: 添付ファイルのUUIDローカルストレージ保存と安全な物理削除

## ステータス
承認済み (Accepted)

## コンテキスト
資格証明書等の添付ファイル（最大10MB）を安全に保管し、社員・資格削除時のデータ不整合（DBと物理ファイルのズレ）を防止する必要があります。

## 意思決定
1. ファイル本体はDBに格納せず、UUIDベースの安全なファイル名でローカルストレージに格納。
2. MIMEタイプ・マジックナンバー・拡張子を厳格検証。
3. 将来のClamAV連携を考慮した `VirusScanner` インターフェースを定義（初期はNoOp）。
4. 削除時はDBトランザクションのコミット完了を確認した後に物理ファイルを削除し、DBロールバック時の孤立ファイルや誤削除を防止。

## 結果と影響
- Path Traversalや不正実行可能ファイルの混入を防止。
- トランザクション補償によりDBとファイルシステムの整合性を維持。
