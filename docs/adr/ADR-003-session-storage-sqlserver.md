# ADR-003: SQL Serverによるセッション管理とHttpOnly Cookie

## ステータス
承認済み (Accepted)

## コンテキスト
安全なセッション永続化と即時無効化（ログアウト、管理者リセット、アカウントロック）が必要です。

## 意思決定
1. セッション情報はSQL Serverの `sessions` テーブルで管理（トークンのSHA-256ハッシュを保管）。
2. クライアントには `HttpOnly; Secure; SameSite=Lax` Cookie でセッションIDを配布。
3. `localStorage` には認証トークンを一切保存しない。

## 結果と影響
- XSSによるセッション盗用リスクを最小化。
- サーバー側での一括ログアウトやアカウントロック時のセッション無効化が即座に反映可能。
