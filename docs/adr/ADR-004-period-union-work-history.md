# ADR-004: 実務経歴の重複期間Union算出アルゴリズム

## ステータス
承認済み (Accepted)

## コンテキスト
複数プロジェクトの同時従事による実務年数の過大計上（水増し）を防ぐ必要があります。

## 意思決定
1. 案件の開始年月〜終了年月を月次インデックス区間に正規化。
2. 同一技術または全案件の区間リストに対して区間マージ（Interval Union）アルゴリズムを適用。
3. マージ後の純粋な従事月数を合計し、実務年数（例: 1年5ヶ月 / 1.4年）を算出。

## 結果と影響
- 案件重複があっても正確な実務経験年数が算出され、人材検索でのマッチング精度が飛躍的に向上。
