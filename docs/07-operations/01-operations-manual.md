# 運用・保守手順書

## 1. 定常運用
1. **サービス死活監視**:
   - `GET /health` (200 OK)
   - `GET /ready` (200 OK, DB疎通確認)
2. **ログ監視**:
   - バックエンドは JSON 形式で標準出力およびログファイルに出力。
   - `level: "error"` のアラート検知。

## 2. バックアップとリストア
1. **データベースバックアップ (SQL Server)**:
   - 日次フルバックアップ + 差分バックアップ (`BACKUP DATABASE skillmatrix TO DISK = '...'`)
2. **添付ファイルストレージバックアップ**:
   - `UPLOAD_DIR`（証明書ファイル等）のディレクトリ同期・バックアップ。
3. **リストア手順**:
   - DB復元と同時に、該当タイムスタンプのファイルストレージを同期復元。

## 3. 監査ログ運用
- 監査ログテーブル (`audit_logs`) は INSERT のみ許可され、UPDATE / DELETE は禁止。
- 3年〜7年の保持期間ポリシーに基づき、古いログはアーカイブテーブルまたはCSVエクスポートにて退避。

## 4. トラブルシューティング
- **アカウントロック解除**:
  - 管理者画面からのリセット、または管理者API (`/api/v1/auth/reset-password`) による即時解除。
- **DB接続エラー**:
  - `Server=localhost\SQLEXPRESS` のサービス稼働状態およびTCP/IPプロトコル有効化の確認。
