# プロジェクト概要 (SkillMatrix)

## 1. 概要
SkillMatrix は、システム開発組織における人材情報（組織、社員、保有資格・添付証明書、実務経歴、部署固有スキルセット、自己評価・所属長評価、評価履歴、人材検索、組織集計、ダッシュボード、監査ログ）を一元管理するWebアプリケーションです。

## 2. 開発背景と目的
- **スキル・経験の可視化**: 部署ごとの専門スキルと、全社共通の客観的な評価基準を両立し、適切な人員配置と育成計画を支援します。
- **高精度な人材検索**: 案件実務経験（重複期間を正しく算出した実稼働年数）、スキル評価、保有資格を複合した高精度な検索を実現します。
- **完全オフライン運用**: セキュアな社内ネットワーク（インターネット遮断環境）において、外部CDNやAPIに依存せず完全ローカルで自律稼働します。
- **オープンソース品質**: 高いセキュリティ水準（RBAC、IDOR防止、CSRF、監査ログ、パスワード保護）と保守性を備えたオープンソースソフトウェアとして公開可能な品質を提供します。

## 3. 主要機能一覧
1. **認証・セッション管理**: ログイン、ログアウト、パスワード変更、初期パスワード強制変更、アカウントロック（5回失敗で15分）、セッション管理（SQL Server保管、HttpOnly Cookie）
2. **組織管理**: 階層ツリー構造の部署管理、部署異動・階層変更
3. **社員管理**: 基本情報管理、在籍状態管理、将来の外部社員マスタ連携を考慮した設計
4. **スキル管理**: 部署固有スキルセット定義（カテゴリ・スキル名・備考）、自己評価・上長評価（A/B/C/未評価）の同時表示、評価履歴追跡
5. **保有資格・ファイル管理**: 資格マスタ＋自由入力、証明書等の添付ファイル（最大10MB, PDF/PNG/JPG/JPEG）、ローカルUUID保存、MIME/拡張子検証、パストラバーサル防止、将来のVirusScanner連携IF
6. **実務経歴管理**: 案件名、業務内容、役割、期間、使用技術。重複期間Unionによる実経験月数・年数の算出
7. **人材検索**: 複合条件検索（氏名、社員番号、部署、役職、資格、スキル評価、実務経験年数、使用技術）、5000人規模対応のINDEX最適化とServer-side pagination
8. **人員一覧**: サーバーサイドページネーション (25/50/100件)、ソート、フィルター、カラム表示制御
9. **ダッシュボード**: ロール別（ADMIN/MANAGER）の組織集計、資格保有率、スキル分布、自己/上長評価ギャップ、経験年数分布、未評価スキル
10. **監査ログ**: 不変監査ログ、操作者、日時、アクション、対象、前後差分スナップショット、IP、Request ID
11. **安全な物理削除**: トランザクション対応の関連データ削除およびファイル整合性保証
12. **多言語 & テーマ**: 日本語/英語 (i18n)、Light/Dark/System テーマ
13. **運用・ヘルスチェック**: `/health`, `/ready` エンドポイント、明示的なDBマイグレーション
