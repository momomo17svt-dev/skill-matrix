# 機能要件定義書

## 1. 認証・認可機能
- **FR-AUTH-001: ログイン**: ログインIDとパスワードによる認証。安全なパスワードハッシュ（bcrypt / argon2相当）を使用。
- **FR-AUTH-002: アカウントロック**: 連続5回認証失敗時に15分間アカウントを自動ロック。
- **FR-AUTH-003: セッション管理**: SQL Serverテーブルで管理されるDBセッション。Cookieは `HttpOnly; Secure; SameSite=Lax` を適用。
- **FR-AUTH-004: パスワード変更**: 一般ユーザーの任意変更、および初回ログイン時の強制変更フラグ制御。
- **FR-AUTH-005: 初期管理者Bootstrap**: 環境変数 `ADMIN_INITIAL_LOGIN_ID`, `ADMIN_INITIAL_PASSWORD` 等から安全に管理者を作成。

## 2. 組織・部署管理機能
- **FR-ORG-001: 階層ツリー構造**: 任意階層（ルート部署〜子部署・孫部署）をサポート。
- **FR-ORG-002: 部署一覧・CRUD**: 部署の作成、名称変更、親部署変更、削除。
- **FR-ORG-003: 配下部署自動解決**: 部署長が選択された場合、自部署およびすべての配下子孫部署を自動集約して管理対象とする。

## 3. 社員管理機能
- **FR-EMP-001: 基本情報管理**: 社員番号、氏名、氏名カナ、メールアドレス、所属部署、役職、システム権限、入社日、在籍状態（在籍/休職/退職）、備考。
- **FR-EMP-002: 外部社員マスタ境界**: 社員基本情報リポジトリインターフェースを分離し、将来外部連携へ差し替え可能とする。
- **FR-EMP-003: サーバーサイドページネーション**: ページサイズ 25/50/100件、ソート、フィルタリング、カラム表示切替。

## 4. スキル管理・評価機能
- **FR-SKL-001: 部署固有スキルセット**: スキルは所属部署ごとに定義され、他部署と独立。カテゴリ・スキル名・備考を保持。
- **FR-SKL-002: 4段階スキルレベル**:
  - `A`: 指導可能
  - `B`: 一人で実務遂行可能
  - `C`: 支援があれば遂行可能
  - `UNEVALUATED`: 未評価
- **FR-SKL-003: 自己評価・上長評価**: 同一スキルに対して自己評価と所属長評価を別個に保持し、並列表示。
- **FR-SKL-004: 評価履歴**: 評価変更日時、評価者ID、新旧レベル、変更理由をタイムラインで記録。

## 5. 保有資格・証明書管理機能
- **FR-CRT-001: 資格マスタ選択＋自由入力**: 既定のマスタからの選択および自由入力による資格登録。
- **FR-CRT-002: 資格情報**: 取得日、有効期限、資格番号、備考。
- **FR-CRT-003: 添付ファイル管理**: PDF/PNG/JPG/JPEG（最大10MB）。ローカルファイルストレージへUUID保存、DBにはメタデータのみ保持。MIME/拡張子/パストラバーサル防止検証。将来のVirusScanner連携IF。

## 6. 実務経歴・期間計算機能
- **FR-WRK-001: 経歴情報**: 案件名、業務内容、役割、開始年月、終了年月（または現在進行中）、備考、使用技術・スキルタグ。
- **FR-WRK-002: 重複期間Union算出**: 複数案件の期間が重複する場合、重複を除いたユニーク実稼働月数を集計して実務経験年数を算出。

## 7. 人材検索機能
- **FR-SRC-001: 複合条件検索**: 氏名、社員番号、部署、役職、資格、スキルレベル（自己/上長）、実務経験年数、使用技術によるAND/OR検索。
- **FR-SRC-002: 高速クエリ設計**: 5000人規模でインデックスを活用した高速検索。

## 8. ダッシュボード・集計機能
- **FR-DSH-001: ロール別集計**: ADMINは全社、DEPARTMENT_MANAGERは管理下部署の統計。
- **FR-DSH-002: KPIグラフ表示**: 総人数、資格保有率、スキル分布、評価ギャップ（自己 vs 上長）、経験年数分布、未評価スキル一覧。

## 9. 監査ログ機能
- **FR-AUD-001: 不変ログ記録**: 実行日時、操作者（ID/氏名）、操作種別、対象種別/ID/社員番号/氏名、変更前JSON、変更後JSON、IP、Request ID。
- **FR-AUD-002: 物理削除時の保持**: 人員削除後も監査ログは削除せず、対象者情報スナップショットを維持。

## 10. 安全な物理削除機能
- **FR-DEL-001: トランザクション削除**: 人員削除時、関連データ（評価、経歴、資格メタデータ等）をDBトランザクション内でカスケード削除。
- **FR-DEL-002: ファイル削除整合性**: DBコミット成功後に実ファイルを削除し、失敗時はロールバック。
