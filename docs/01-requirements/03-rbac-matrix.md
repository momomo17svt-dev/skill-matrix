# 権限マトリクス (RBAC Matrix)

## 1. ロール定義
- **ADMIN**: システム全体管理者。全部署・全社員・全マスタ・監査ログの管理権限を保持。
- **DEPARTMENT_MANAGER**: 部署長。自部署およびすべての配下子孫部署の社員閲覧・編集、スキルセット定義、所属長評価入力、部署集計権限を保持。
- **GENERAL**: 一般社員。自身および同じ直属部署（同一部署ID）の社員の閲覧、自身の資格・実務歴・自己評価の編集権限を保持。

## 3. IDOR (Insecure Direct Object References) 対策方針
- フロントエンドの非表示制御に依存せず、すべてのバックエンドAPIエンドポイント（`/api/v1/employees/:id/*`等）において、リクエスト送信者のロールと対象リソースの所属部署パスを照合して認可判定を行います。
- GENERALロールが他部署または同僚の変更APIを叩いた場合は `403 Forbidden` を返却します。
