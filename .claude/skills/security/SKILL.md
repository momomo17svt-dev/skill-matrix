# Security Skill

## チェック項目
- [ ] 認可チェックがAPIレイヤーで完全に行われているか
- [ ] DEPARTMENT_MANAGER / GENERAL が別部署のデータを更新・取得できないか (IDOR)
- [ ] ログイン失敗5回で15分ロックアウトされるか
- [ ] ログにパスワード、トークン、機密情報が出力されていないか
- [ ] 監査ログが物理削除されずに残るか
- [ ] ファイルアップロード時のMIME/拡張子/パストラバーサル検証
